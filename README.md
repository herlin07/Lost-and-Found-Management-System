# Lost and Found Management System

## 📌 Project Overview
The **Lost and Found Management System** is a web-based application developed using Python and Flask. It helps students report lost and found items in one place, making it easier to find missing belongings and return items to their owners.

## 🎯 Objectives
- To make reporting lost and found items easy.
- To help students find their missing belongings.
- To maintain records of reported items.
- To make the process of finding lost items easier.

## ✨ Features
- Report lost items.
- Report found items.
- Enter item details such as name, category, location, and date.
- Add a description of the item.
- Store student details for reporting.
- Maintain records of reported items.
- Track the status of reported items.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Web Framework:** Flask
- **Database:** SQLite
- **Database Integration:** Flask-SQLAlchemy
- **Frontend:** HTML and CSS
- **Template Engine:** Jinja2
